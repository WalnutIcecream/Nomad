# Nomad

Nomad turns any friend into the host, automatically.

Start a world. Press Play. The first one in runs the server. Everyone else joins. When the host stops, the world syncs. Whoever plays next picks up where it left off.

No rented servers. No logins. No upkeep. If you can share a file, you can host together.

## How it works in one line

A shared cloud folder holds the world and a "who is hosting" marker. First to claim the marker hosts; the rest connect.

## What you need

- A free Cloudflare R2 bucket (or a git repo, or your own server).
- One file with three values.
- That's it.

## Why it's different

- Nothing runs when you aren't playing.
- No accounts to create.
- No monthly bill.
- Impossible for two people to host at once.
- If the host crashes, the world frees itself.

## Get it

Run the app. Paste three values. Make a world. Share the world ID.
